Keys

The default key map, as the app ships it. Every one of these can be changed, removed or limited to some sites in Settings › Keyboard; a site pack or your own website settings may add keys on top, or hand some of these back to the site.

Modes

Like vim, Vimlike is modal. Which mode you are in decides what a key does.

ModeWhat it is
NormalThe keys below work. This is where a page starts (or Insert, per site or globally in Settings › General).
InsertEvery key goes to the page. You enter it by clicking into a field, with i or ⌃i; Esc brings Normal back. On a keyboard without a comfortable Esc, Settings › Keyboard can make ` or § act as Esc.
LinkAfter f or ⇧F: every link and button carries a label; typing it opens the link. n / ⇧N move the selection, ↩ opens it, ⌫ deletes a typed letter, Esc leaves.
VisualSelect text with vim's motions: v, ⇧V for lines, c for a caret without a selection. The keys.
BarThe bar is open (o, / or :). It has keys of its own.

Two-key sequences. Keys like gg are pressed one after the other, not held together. A key written ⌃f is held with Control; ⇧G is Shift and G.

Visual mode

Press v on a page and a selection starts at the top of what is on screen; ⇧V selects whole lines; c places a caret you can move first. Inside, the keys are vim's, and every other key is swallowed so a stray letter cannot scroll you away.

KeyDoes
h j k lMove the cursor, extending the selection
w b eBy word: forward, back, to the end of the word
0 $To the start or end of the line
gg · ⇧GTo the start or end of the page
f t · ⇧F ⇧TJump to the next (or previous) typed character on the line; ; and , repeat the search either way
aw · asSelect the word or the sentence under the cursor
oSwap which end of the selection moves
v ⇧V cSwitch between character, line and caret selection
yCopy the selection and leave visual mode
/Find text from the cursor; n / ⇧N for the next and previous match. The prompt is a real field, so Korean, Japanese and Chinese input methods work in it
:Ask the AI about the selection
EscBack to Normal mode, selection kept

In the bar

The bar opens with o. Typing searches at once; / or : as the first key switches it to link search or the command palette, and ⌫ on an empty bar switches back.

KeyDoes
↩Open the highlighted row — a tab, a history entry, a web search, a saved command
⌘↩Send what you typed to the AI as a question, from any mode of the bar
↓ ↑ · Tab ⇧TabMove the highlight
↑ on an empty barWalk back through what you ran before, like a shell; what you ran on this site comes first. ↩ brings its suggestions up instead of running it. ⇧↑ / ⇧↓ walk history even with text in the bar
⌃j ⌃k ⌃f ⌃bScroll the page behind the bar (a line, a page) without closing it
⌃[ · EscClose the bar. ⌃[ is for iPadOS, which keeps Esc for itself while a field has focus

The history and scroll keys can be turned off in Settings › Search Bar.

System keys

Three keys are bound before any key map loads and cannot be remapped or given back to a site: Esc returns to Normal mode, ↩ opens the selected link in link mode, ⌫ deletes a typed label letter. Tab is never released to a site either.
