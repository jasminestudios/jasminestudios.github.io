Commands 2.0.2

Press : on any page and the bar becomes a command line: Vimlike's own commands, grouped by what they do, beside this site's keys and your AI commands. Type a few letters to narrow it, ↩ to run. It is vim's :, for the web.

Using it

  • : alone lists everything, in sections: This site first (the site pack's keys and the AI commands for this site), then Page, Clean up, Video, Copy and Share, Navigate, Tabs and Windows, Tab Groups, Close Tabs, Search and Vimlike, then your AI Commands.
  • Typing filters across all of them by name, shortcut or alias: :dar finds Dark Mode, :q Close Tab. Shortcuts can be cut short — :vers runs :version.
  • Text after a command is its argument: :zoom 150, :speed 1.5, :g safari extensions. The row shows what the command takes, and a command that needs one waits for it.
  • A row with a key shows it as key caps at its right edge, so ⇧H or gw is there to learn next time.
  • Hard-to-undo commands ask first — closing several tabs, deleting a tab group, removing a site pack. ↩ goes ahead, Esc stops.
  • Nothing matches? With the AI assistant on, what you typed becomes a question: the lit Ask AI row sends it.
  • Recent — on an empty :, the last commands you ran on this site come first; ↑ walks back through them too. :. runs the last command again.

Where it works. Commands marked Mac only need macOS Safari's window and tab controls. Video commands appear only on pages with a video, Share only where Safari can share.

Tab Groups

A tab group is a named set of tabs you can switch a window between: Work in the morning, Trip in the evening. A window shows one group at a time. Switching keeps the window's tabs under the group it was showing, closes them, and opens the other group's — so it works the same on iPhone, iPad and Mac. Tabs in a window that showed no group are kept under Other Tabs, so switching never loses them.

CommandDoes
:group save nameSave this window as a groupKeeps the window's web pages under that name, and the window now shows that group.
:group nameSwitch to a group:group alone lists them with their tab counts; a few letters are enough. Aliases :tg, :groups.
:group new nameStart an empty groupThe window's tabs are kept under the group it was showing.
:group move nameMove this tab to another groupThe tab leaves this window and waits in that group; a new name makes a new group.
:group delete nameDelete a groupAsks first. Open tabs are not closed.
:groupnext
:groupprev		Next · previous groupIn the order the groups were saved. Aliases :gnext, :gprev.

The keys: gw lists the groups, g] and g[ step through them.

Good to know. These are Vimlike's own groups, separate from Safari's Tab Groups, which extensions cannot reach. A reopened tab starts fresh — no back history, no half-filled form. Pinned tabs stay put. Only web pages go in a group, and nothing from a private window is kept. If another window already shows the group you ask for, Vimlike brings that window forward instead of opening it twice. Groups saved with :session in earlier builds are tab groups now.

With the AI assistant in Direct API mode, three more act on the website you are on: :keys (Suggest shortcuts), :clean (Clean up this page) and :repair — see Websites & site packs. Your saved AI commands, such as :sum and :translate, are in AI assistant.

:set options

Vim's forms: :set smoothscroll turns an option on, :set nosmoothscroll off, :set smoothscroll! flips it, and :set engine=duckduckgo gives a value. :set alone lists every option with its current value. A change is saved as if made in the app's Settings.
