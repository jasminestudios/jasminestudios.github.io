Keyboard

Vim's keys, on every page.

h j k l, gg, G, d, u. Link hints turn every link on screen into a one- or two-letter jump.

  • Link hints f labels every link; type the label to open it. ⇧F opens in a background tab.
  • Tabs t new, x close, q / w previous and next, ⇧Z reopen, g1…g9 by number.
  • Modes Normal to navigate, Insert to type. Esc returns; ` or § can stand in for it on iPad keyboards.
  • And Dark mode per site, video full screen and picture in picture, zoom, up one URL level, copy the URL, ? for the cheat sheet. Every key →
Search Bar

Tabs, history, the web.
One place to search.

Press o and type. The bar searches your open tabs, your local history, your top sites and the web in one list. ↩ opens the highlighted row; ⌘↩ sends the text to the AI instead.

  • History like a shell ↑ on an empty bar walks back through what you ran. What you ran on this site comes first.
  • : for commands Saved AI commands as you type. :keys, :clean and :repair act on the site you are on.
  • / for a link by name Filters the page's links as you type. ↩ opens.

1 AI Assistant

Ask about the page.
Or have it do the work.

Press o, type a question, press ⌘↩. The answer streams into the bar, over the page. Ask for work instead and it does the work: it clicks, types, picks from menus, pulls tables out, opens tabs, reads your other tabs. 28 tools. It asks before anything it cannot undo.

  • Saved commands :sum, :table, :translate korean, :links. Make your own: a prompt, a shortcut, optionally a key and a site it belongs to.
  • Permissions Five kinds of tool — read, open and click, type, change the page, screenshot — each Allow, Ask or Deny. A step limit per run.
  • Reports A long answer opens as a page: headings, tables, Copy Markdown, Print.

It asks before it clicks Delete, Pay or Submit.

2 AI Assistant · Apple Intelligence

Works out of the box
with Apple Intelligence.

Pick Apple Intelligence as the provider and the assistant runs on Apple's Private Cloud Compute. Nothing to sign up for, nothing to pay, nothing kept. It needs a device and OS that offer Apple Intelligence.

  • Or your own key Claude, OpenAI, Gemini or DeepSeek. Pick a model per task. The key goes in the Keychain, not in settings and not in iCloud.
  • Usage, on the device Settings keeps the last 200 requests by model and task, so you can see what costs tokens.
3 AI Assistant · Open in browser

Use the ChatGPT or Claude
you already have.

Open in browser mode opens ChatGPT, Claude, Gemini, Perplexity or DeepSeek in a new tab with your prompt and the page's text already typed in. It uses the chat account you have. No key, no cost beyond that.

  • The same commands :sum, :kr, :translate and any command that only reads the page work this way too.
  • One switch Settings › AI Assistant › Mode: Direct API or Open in browser. Then pick the chat service.
4 AI Assistant · Create shortcuts

Shortcuts the AI makes
for each site.

Open the toolbar popup on a site and press Suggest shortcuts. The AI reads the page's places and proposes keys: gh home, gs search, go the top story. The keys work while you try them. Save keeps them in that website's settings; Esc discards.

  • Change it in words "A key for the Subscribe button." "Use other keys for World." "Turn on Watch." Chips start the sentence.
  • No code The AI names an element and a key. Vimlike builds the selector and checks it on the page before showing it. A key is a click or an address, never a script.
  • By hand gk on any page: click an element, press a key, name it.
5 AI Assistant · Clean up the page

Hide the ads.
Keep the article.

Clean up this page in the popup, or :clean in the bar. Say what should go, or pick a chip: ads, banners, the sidebar, comments. The AI answers with areas to hide or dim. The page changes before you save. Styles, not scripts; each one can be removed later.

  • Three moves Hide, dim, or show on hover. The main text of the page can never be hidden.
  • Listed in words The popup and Settings › Websites show each style by name, with a ✕.
6 Keyboard customization

Change any key.
No script to write.

Settings › Keyboard lists every command by group. Pick a command, record a key, exclude the shortcut on sites where it gets in the way. Conflicts are flagged as you go. The settings script is still there, in Script mode, for anyone who prefers to write it.

  • Three modes Default shows the shipped map. Custom edits it as a table. Script edits the JavaScript directly.
  • Record, don't type Press the keys; two in a row make a sequence like gg. Link-mode keys are grouped apart and may overlap normal-mode keys.
7 Site packs

Ready-made keys
for the sites you use.

A site pack is one signed file for one website: keys for its places, a few AI commands, CSS, and the Vimlike keys it hands back so the site's own shortcuts still work. Packs for YouTube, Gmail, Google Search and News, Reddit, Wikipedia, GitHub, Hacker News, Netflix and more. Install from the popup, or from Settings › Websites.

  • Verified, no JavaScript Checked on your device each time it runs. A pack can click, open, run a short list of steps, hide and dim. It cannot run code.
  • Versioned A new version shows an Update button. Updating keeps your switches and re-keyed keys.
  • Yours stays yours Your keys, styles, AI commands and CSS sit beside the pack, win over it, and can be removed on their own.
8 Visual & caret mode

Select text
with vim motions.

v starts a selection at the top of the screen; ⇧V selects by line; c places a caret you move first. Then vim's motions: h j k l, w b e, 0 $, f and t to a character, aw a word, as a sentence. Other keys do nothing, so a stray letter cannot scroll you away.

  • Then y copies and leaves. : asks the AI about the selection. / finds text from the cursor; n and ⇧N step through matches.
  • Input methods work The find prompt is a real field, so Korean, Japanese and Chinese can be typed into it.

Questions

Do I need an API key?

Not for the keyboard or the bar. For the AI, Apple Intelligence needs none. Other providers need your own key. Open in browser mode needs no key either; it uses the chat website.

Which devices?

iPhone, iPad, Mac and Apple Vision Pro. iOS and iPadOS 16.6 or later, macOS 13 or later.

Can I change the shortcuts?

All of them, in Settings › Keyboard: a table of every command, a recorded key per row, exclusions per site, conflicts flagged. A settings script is there for anyone who prefers it. Details →

What is a site pack?

One signed file for one website: keys for its places, a few AI commands, optional CSS, and the Vimlike keys it hands back to the site. Published by Jasmine Studios, verified on your device each time it runs, no JavaScript. Details →

Does the AI change my settings or the page?

Only what you keep. Suggest shortcuts and Clean up this page show a draft you try first. Save writes keys and styles into that website's settings; Discard drops them. The AI never writes code into Vimlike.

Is my browsing sent anywhere?

No. There is no analytics on browsing and no Vimlike server. What you ask the AI goes to the provider you chose.

Languages?

English, Korean, Japanese, Chinese (Simplified and Traditional), Cantonese, German, Spanish, French, Italian, Portuguese.
