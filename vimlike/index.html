Keyboard

Vim's muscle memory,
on every page.

The keys you already know — h j k l, gg, G, d, u — and link hints that turn every link on screen into a two-letter jump.

  • Link hints Press f and every link gets a label. Type it to open; ⇧F opens in a background tab. Optionally put images, videos and headlines first.
  • Tabs without the mouse t to open, x to close, q / w to move between, ⇧X to bring one back.
  • Modes, like vim Normal to navigate, Insert to type. Esc — or ` / § if that's easier on your layout — always takes you back.
  • Remap anything — in a table 2.0 Settings › Keyboard lists every command by group. Record a key, exclude the shortcut on the sites where it gets in the way, see conflicts as you go. The settings script is still there for anyone who would rather write it.
  • Select text like vim v starts a selection, ⇧V by lines, c a caret. w b f move it, y copies, : asks the AI about it.
  • The rest of it Dark mode on any site, reader view, video fullscreen and picture-in-picture, zoom, go up a URL, copy the URL, and ? for the cheat sheet.
Search Bar

One bar instead of
four places to look.

Press o and start typing. Vimlike searches your open tabs, your local history, your most-visited sites and the web at once — and the same bar is where you talk to the assistant: ⌘↩ asks instead of searching.

  • Everything in one list Top site, open tabs, local history and web search suggestions, ranked together. Enter opens what's highlighted.
  • History that works like a shell ↑ on an empty bar walks back through what you ran before — and what you ran on this site comes back first.
  • Type : for commands Your saved AI commands appear as you type. :sum, :table, :kr — or the ones you make. :keys and :clean shape the site you're on.
  • Find a link by name / filters the page's links as you type. Enter opens.
AI Assistant

An assistant that can use
the page, not just read it.

Ask a question, get the answer inline. Ask for something done and it clicks, types, extracts, opens tabs and reports back — stopping to ask you first before anything it can't undo.

  • It operates the page 28 tools: it reads the article, clicks buttons, fills forms, picks from dropdowns, pulls tables into rows, scrolls, navigates, opens tabs, reads your other tabs, searches your history, takes a screenshot when the answer is visual.
  • Commands you keep Give any prompt a :shortcut. Limit it to one site so it only shows up there. Give it a key and it runs without opening the bar at all.
  • Permissions you set once Read the page, open pages and click, type into pages, change the page, take screenshots — each Allow, Ask or Deny. A step limit per run, and per command.
  • Reports, not walls of text Long results open as a formatted page you can copy as Markdown or print to PDF.
  • Memory and skills Standing preferences — “always answer in Korean”, “compare prices with shipping” — travel with every request. Attach step-by-step instructions to a command and it follows them.
  • Your provider, your key Apple Intelligence needs no key and runs on Private Cloud Compute, where nothing is kept. Or bring your own key for Claude, OpenAI, Gemini or DeepSeek. Or skip the API entirely — “Open in browser” mode drops the page and your prompt straight into ChatGPT, Gemini, Claude, Perplexity or DeepSeek.

Websites & Site Packs · New in 2.0

Keys for the sites
you actually live in.

A global key map is only half of it. On Gmail you want gi for the inbox; on CNN, gw for World. Vimlike gets you there two ways, and never with code.

  • Suggest shortcuts One button in the popup. The AI looks at the site's places and proposes keys for them — gh home, gs search, go the top story — live, to try before you save. Say what to change in your own words.
  • Clean up this page Ads, banners, the sidebar, the comments — hidden or dimmed on request. Styles, not scripts, and each one removable.
  • Site packs, signed Ready-made keys for YouTube, Gmail, Google Search and News, Reddit, Wikipedia, GitHub, Hacker News, Netflix and more — signed by Jasmine Studios, checked on your device every time, versioned, updated when you say. A pack can click, open and restyle. It cannot run JavaScript.
  • Yours and the pack's, kept apart Your keys, styles, AI commands, CSS and switches live beside the pack, win over it, and can be removed on their own. Press gk on any element to give it a key by hand.

There is no Vimlike account and no Vimlike backend. Install it and it works.

The history the search bar searches is stored on your device, and you can delete it in Settings whenever you like.

Not in a settings file, not in iCloud, and never handed to the web page you're on.

Questions, answered.

Do I need an API key?

Not for the keyboard or the search bar — those need nothing. For AI, Apple Intelligence runs on-device for free on supported devices. Other providers need your own key, or you can use “Open in browser” mode, which uses ChatGPT, Gemini, Claude or Perplexity through their own websites.

Which devices does it work on?

iPhone, iPad, Mac and Apple Vision Pro — iOS and iPadOS 16.6 or later, macOS 13 or later.

Can I change the shortcuts?

All of them. Settings › Keyboard is a table of every command: record a key, exclude a shortcut on specific sites, see conflicts. A settings script is there for anyone who prefers writing it. How it works →

What is a site pack?

One signed file for one website — keys for its places, a few AI commands, optional CSS that tidies it, and the Vimlike keys it hands back so the site's own shortcuts keep working. Packs are published by Jasmine Studios, verified on your device each time they run, and contain no JavaScript. More →

Does the AI change my settings or the page?

Only what you keep. Suggest shortcuts and Clean up this page show a draft you try first; Save writes keys and styles into that website's settings, Discard throws it away. The AI never writes code into Vimlike.

Does it change how sites look?

Only when you ask it to. Dark mode, custom CSS and custom scripts are per-site and off by default.

Is my browsing sent anywhere?

No. There's no analytics on your browsing and no Vimlike server to send it to. The only thing that ever leaves your device is what you explicitly ask the AI about, and it goes to the provider you chose.

What languages is it in?

English, Korean, Japanese, Chinese (Simplified and Traditional), Cantonese, German, Spanish, French, Italian and Portuguese.
