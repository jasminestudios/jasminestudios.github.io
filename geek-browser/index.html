AI agent

Ask it anything.
Or hand it the whole task.

Type a question in the address bar and press Enter: it answers from the page you are on. Give it a task and it opens a copy of the page in its own tab, marked ✦, and works through it while you keep reading. Every step, every token and the running cost show in the side panel.   • Reads, clicks, types Summarize, translate, extract a table into a report, fill a form, follow links, open the five links that matter in background tabs.
  • Three permission levels Read only never acts. Guard asks before submitting, paying, posting, deleting or leaving the site. Full access acts on its own. You choose, per run.
  • Knows your tabs Type @ to bring another open tab into the question. Select text on the page and ask about it from the edit menu.

Vim-like keyboard

Vim-like browsing,
the whole way down.

Press f and every link gets a two-letter label — type it to open. o opens the address bar, : a command palette, / finds in the page. j k scroll, ⌘⇧] walks the tabs. If you know Vim or Vimlike, you already know Geek Browser.

  • Link hints f labels the links on screen; n / ⇧n step through them; Enter opens, ⇧Enter opens in a new tab. Point and press a to click whatever is under the cursor.
  • Command palette : lists every command with its key — and your saved AI commands sit at the top. :tab, :set darkmode=true, :javascript, :ping, and your own.
  • A help bar that teaches A one-line bar shows the keys for the mode you are in and lights up the one you pressed. Hide it when you know them.
  • Yours to remap Every key is a setting. Sequences like g g and y y work. Bind keys per website, or import your Vimlike settings.

Works with any hardware keyboard — Magic Keyboard, a Bluetooth keyboard, or the one on your Mac.

Questions, answered.

Where does the AI agent actually run?

In the browser on your iPad. It drives a real tab — the ✦ tab — using the same session you are already signed into, so nothing is copied anywhere. Only the model call leaves the device, and only to the provider you picked. With Apple Intelligence on-device, not even that.

Which models can I use?

Apple Intelligence on-device and Apple's Private Cloud Compute need no key at all. For Claude, OpenAI, Gemini or DeepSeek you add your own API key, kept in the Keychain. You can change model per task.

What does the AI cost?

Nothing on-device. With your own key you pay your provider at their prices, with no markup from us. The panel shows tokens and estimated cost while a task runs, and you can set a budget per task. A saved command that already worked replays without the model, for free.

Can a web page hijack the AI agent?

Everything read from a page is fenced as untrusted content, so text on a page is data to read, never an instruction to follow. On top of that, Guard mode stops for your approval before submitting, paying, posting, deleting or leaving the site, every run has a step limit, and Esc ends it immediately.

Do I need an account?

No — there is nothing to sign into. No sign-up, no profile, no sync service of ours.

Is it really free?

Yes. No in-app purchases, no subscription, no ads, and the AI agent is not behind a paid tier.

Do I need a keyboard?

Geek Browser works by touch too, but it is built for a hardware keyboard: Magic Keyboard, any Bluetooth keyboard, or a Mac's.

Does it run on my Mac?

Yes, on Apple silicon Macs as an iPad app from the Mac App Store, with the same keys.

What about passkeys and saved passwords?

Geek Browser is a real browser to iPadOS, so iCloud Keychain fills passwords and passkeys on any site. The AI agent never sees them: it stops at sign-in pages and hands you the tab.

Can I use my Vimlike settings?

Yes. Export from Vimlike's Website Settings and import the file in Settings › Websites. Key names, site scripts and per-site commands come along.
